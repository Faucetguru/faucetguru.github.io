# Plan de Tareas para el Agente Hermes (SEO Crypto)

## Objetivo General
Identificar oportunidades de tráfico orgánico de baja competencia para un blog enfocado en faucets, wallets, minería, earning apps y ecosistemas crypto emergentes.

---

## Skills Requeridos

### Skill: Web Research
Responsabilidades:
- Analizar tendencias de búsqueda relacionadas con crypto.
- Identificar nuevas blockchains, testnets y faucets.
- Detectar keywords long-tail con baja competencia.
- Revisar comunidades, documentación oficial y motores de búsqueda.
- Extraer oportunidades que aún no estén cubiertas por medios grandes.

Fuentes sugeridas:
- Google Search Console
- AnswerThePublic
- Google Trends
- Documentación oficial de proyectos blockchain
- Foros y comunidades crypto
- Motores de búsqueda tradicionales

### Skill: Redacción (Writing)
Responsabilidades:
- Crear artículos SEO optimizados.
- Generar títulos orientados a CTR.
- Elaborar guías paso a paso.
- Crear comparativas entre wallets y plataformas.
- Redactar contenido orientado a principiantes.

---

## Flujo de Trabajo

### Fase 1: Investigación
1. Buscar nuevas blockchains emergentes.
2. Identificar faucets y testnets recientes.
3. Analizar preguntas frecuentes de usuarios.
4. Detectar errores y problemas comunes en wallets.
5. Encontrar keywords long-tail con baja competencia.

Entregable:
- Lista priorizada de keywords.
- Nivel estimado de competencia.
- Intención de búsqueda.

---

### Fase 2: Agrupación Temática

#### Cluster 1: Faucets
- Mejores faucets para USDT.
- Faucets que pagan en FaucetPay.
- Faucets nuevos 2026.
- Faucets para Sui.
- Faucets para Monad.

#### Cluster 2: Wallets
- Trust Wallet.
- MetaMask.
- Rabby Wallet.
- Phantom.
- Backpack Wallet.

#### Cluster 3: Airdrops
- Testnets activas.
- Faucets para testnets.
- Farming de puntos.
- Guías paso a paso.

#### Cluster 4: Minería
- Cloud mining.
- Minería móvil.
- Minería desde navegador.
- Earning apps.
- Simuladores de minería.

---

### Fase 3: Producción de Contenido

Para cada keyword:

1. Crear título SEO.
2. Crear estructura H1-H2-H3.
3. Redactar contenido completo.
4. Añadir FAQ.
5. Añadir enlaces internos.
6. Añadir llamada a la acción.
